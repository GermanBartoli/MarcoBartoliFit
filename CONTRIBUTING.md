# Cómo colaborar con Marco Bartoli · Entrená con propósito

Para informar un error, describí la sección de Lifestyle y el video, sin datos de consultas personales. Agregá los pasos mínimos para reproducirlo y el resultado que esperabas. Para proponer una mejora, contá qué tarea querés resolver y cómo la harías hoy.

Antes de enviar un cambio, seguí la [guía de uso](GUIA_DE_USO.md) y probá el recorrido que modificaste. En el pull request explicá qué cambió y con qué datos o entorno lo verificaste.
