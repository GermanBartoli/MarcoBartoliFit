# Guía de MarcoBartoliFit

La página de asesoría usa `index.html`, `styles.css`, `script.js` y medios de `assets` y `media`. Revisá `_worker.js` junto con `tests/contact.test.js` al modificar el formulario.

Corré `pnpm run check`, `pnpm test` y `pnpm run build`. Para cambios en los videos, abrí la página con `pnpm run dev` y comprobá la reproducción y el carrusel en pantalla angosta.

Consultá los pasos de publicación en [el flujo de GitHub Actions](.github/workflows/cloudflare.yml). Para verificar los dos sitios publicados, seguí [la guía de publicación](docs/PUBLICACION.md).
